🛡️ Mục 02 • Cài đặt

Hướng dẫn Windows Defender

Khi tải file .exe, Windows SmartScreen có thể hiển thị thông báo "Windows protected your PC" vì đây là phần mềm mã nguồn mở mới phát hành.

1 Bấm vào chữ "More info" (Xem thêm)
2 Chọn "Run anyway" (Vẫn chạy)
✓ Mã nguồn mở 100% minh bạch trên GitHub
Yêu cầu: Windows 10/11 64-bit hoặc macOS
🔒 Mục 03 • Bảo mật

Quyền riêng tư Local-First

Không thu thập dữ liệu nghe nhạc hay bán thông tin người dùng. Danh sách bài hát và lịch sử được lưu trực tiếp vào cơ sở dữ liệu SQLite ngay trên ổ cứng của bạn.

  • ✓ Offline-First: Mở app nghe nhạc ngay cả khi mất mạng
  • ✓ Tùy chọn Supabase: Đồng bộ đám mây chỉ khi bạn muốn
  • ✓ Hỗ trợ tự kết nối Database riêng cho lập trình viên/IT
Database: spytify.db Mã hóa SHA-256
