Siêu nhẹ nhờ lõi Rust

Không đóng gói Chromium như Spotify hay Discord. Spytify dùng WebView2 có sẵn trên Windows nên dung lượng cài đặt chỉ ~15 MB và RAM tiêu tốn thấp kỷ lục.

Spytify~68 MB RAM
Spotify Desktop~450 MB
Discord~500 MB
Khởi động < 0.5 giây Tiết kiệm 80% RAM
🛡️

Hướng dẫn cài đặt

Windows SmartScreen có thể hiển thị cảnh báo với ứng dụng mã nguồn mở chưa có chứng chỉ số doanh nghiệp. Chỉ cần 2 bước đơn giản:

1 Bấm "More info"
2 Chọn "Run anyway"
Windows 10/11 64-bit macOS Universal
🔒

Local-First & Quyền riêng tư

Dữ liệu được lưu trong file SQLite ngay trên máy của bạn. Không thu thập, không theo dõi, không bán dữ liệu. Tùy chọn đồng bộ Cloud khi cần.

✓ Offline-First — nghe nhạc khi mất mạng
✓ Tùy chọn Supabase Cloud Sync
✓ Tự host database riêng cho IT
✓ Mã hóa mật khẩu SHA-256 + Salt
spytify.db (SQLite) Mã nguồn mở MIT
